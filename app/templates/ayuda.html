¿Cómo usar R2-LDT2?

1. Configurar un ambiente

Ir a Configuración → Ambientes y crear un ambiente con los datos de conexión Oracle (host, puerto, service name). Podés tener tantos ambientes como necesites (DEV, QA, PRD).

2. Registrar aplicaciones EBS

En Configuración → Aplicaciones EBS registrá los short names de las aplicaciones que vas a necesitar (FND, PER, GL, etc). Se usan al generar sentencias para objetos que requieren APPLICATION_SHORT_NAME.

3. Generar la sentencia FNDLOAD

Ir a Download Manager, seleccionar el ambiente, ingresar usuario/contraseña de BD, el tipo de objeto y su nombre. La herramienta genera el comando FNDLOAD listo para ejecutar en el servidor EBS.

4. Ejecutar el comando

Copiá la sentencia generada y ejecutala en el servidor EBS con el usuario applmgr (o quien tenga el entorno Oracle seteado). El archivo .ldt se generará en el directorio desde donde corras el comando.

Estructura de sentencia FNDLOAD

FNDLOAD <user>/<pass>@<db> 0 Y DOWNLOAD <LCT_FILE> <output>.ldt <ENTITY> <KEY>="<VALUE>"
user/pass@dbCredenciales y conexión a la base Oracle EBS 0 Y DOWNLOADParámetros estándar: log level, modo debug, acción LCT_FILEArchivo de configuración FNDLOAD (en $FND_TOP/patch/115/import/) output.ldtArchivo LDT que se genera ENTITYEntidad a descargar (ej: FND_MENU, FND_FORM_FUNCTION) KEY="VALUE"Filtro para identificar el objeto específico
